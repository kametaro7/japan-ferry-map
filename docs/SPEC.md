# 日本の定期旅客航路マップ — 調査・台帳作成仕様（全担当共通）

プロジェクト: このリポジトリ（静的サイト。地図に航路線を描き、種別・夜行/船中泊・マイカー搭載でフィルタし、各航路から運航会社サイトへリンクする）

## 目的
日本国内（および日本発着の国際航路）で **一般の旅客が乗船できる定期航路** をできるだけ網羅的に集め、地図アプリの台帳 JSON を作る。**2026年9月時点** の運航状況を反映すること（知識が古い可能性があるので、運航中かどうかは Web で確認する）。

## 収録するもの
- フェリー（自動車航送あり）、旅客船・高速船・ジェットフォイル（旅客のみ）
- 離島航路、市町村営・県営の定期船、渡船（無料の公営渡船も含む。例: 大阪市営渡船、若戸渡船、尾道の渡船）
- 観光船・遊覧船のうち、**時刻表や定時の出航があり、個人客が乗れるもの**（同じ港に戻る周遊コースも可。例: 松島島巡り、鳴門の渦潮観光船、知床観光船）
- 川・運河の水上バス、舟下り・川下り（保津川下り、長瀞ライン下り、柳川川下り、最上川舟下り等、定期的に出航しているもの）
- 湖・ダム湖の定期船・遊覧船（芦ノ湖の海賊船、琵琶湖の竹生島航路、十和田湖遊覧船、庄川峡遊覧船 等）
- 季節運航（夏季のみ・流氷期のみ等）も含める（`seasonal: true`）
- 日本発着の国際旅客航路（担当01のみ）

## 収録しないもの
- 旅客が乗れない航路（貨物専用 RORO 船、トラックドライバーのみ乗船可の貨物フェリー 等）
- 完全貸切・チャーターのみ、屋形船、レストラン船・ディナークルーズ（食事が主目的）、釣り船、ダイビング船、ホエール/イルカウォッチング等の自然観察ツアー、定期ダイヤの無い海上タクシー、水陸両用バス、カヌー/SUP 等のアクティビティ
- 廃止済みの航路（「2019年廃止」等）
- クルーズ客船（定期航路でないもの）
- 長期休航中の航路は `status: "suspended"` で収録してよい（理由と時期を notes に。再開予定が全く無く事実上廃止なら収録しない）

### 長距離フェリーの定義（担当01）
本州・北海道・四国・九州・沖縄本島のうち **異なる本土どうし、または本土と奄美・沖縄** を結ぶ、おおむね航路距離300km以上のフェリー（日本長距離フェリー協会の加盟航路を目安。300km未満でも同協会加盟の長距離航路、例: 大阪南港〜東予港 は01）。
例（要確認）: 新日本海フェリー各航路、太平洋フェリー、商船三井さんふらわあ（大洗〜苫小牧、大阪〜別府、神戸〜大分、大阪〜志布志）、シルバーフェリー（八戸〜苫小牧）、名門大洋フェリー、阪九フェリー、東京九州フェリー、オーシャン東九フェリー、宮崎カーフェリー、オレンジフェリー、マルエーフェリー／マリックスライン（鹿児島〜奄美〜那覇）。
**01が扱わないもの**（各地域の担当が収録）: 東京〜伊豆諸島・小笠原（03）、鹿児島〜トカラ列島・三島村・種子島・屋久島・奄美群島内のみの航路（11）、博多〜五島（10）、那覇〜大東島（12）、津軽海峡（02）、神戸〜高松（05）など、一つの地域内または近距離の航路。

## 出力ファイル
- `data/regions/<番号>_<key>.json`（例: `07_hiroshima.json`）
- 形式: `{"region": "<番号>_<key>", "updated": "2026-09-13", "routes": [ ... ]}`（UTF-8、`ensure_ascii` しない）
- **20〜30件ごとに上書き保存**すること（途中で中断しても成果が残るように）。最後に `python3 -m json.tool <file> > /dev/null` で構文を確認。
- 作業用の一時ファイルは `work/tmp/<番号>/` に置く。他担当のファイルは編集しない。

## 1航路のスキーマ
```json
{
  "id": "07-miyajima-jr",
  "name": "宮島口〜宮島",
  "operator": "JR西日本宮島フェリー",
  "operator_url": "https://jr-miyajimaferry.co.jp/",
  "route_url": "https://jr-miyajimaferry.co.jp/timetable/",
  "service": "ferry",
  "water": "sea",
  "ports": [
    {"name": "宮島口", "lat": 34.31074, "lon": 132.30361},
    {"name": "宮島", "lat": 34.30074, "lon": 132.32172}
  ],
  "loop": false,
  "car": true,
  "car_note": "",
  "bike": true,
  "bicycle": true,
  "overnight": false,
  "overnight_note": "",
  "international": false,
  "countries": ["JP"],
  "prefectures": ["広島県"],
  "seasonal": false,
  "season_note": "",
  "status": "active",
  "duration": "約10分",
  "frequency": "1時間に4便程度",
  "vessels": "フェリー",
  "osm": ["way/123456789"],
  "notes": "",
  "sources": ["https://jr-miyajimaferry.co.jp/"],
  "confidence": "high"
}
```

### 各フィールド
- `id`: `<番号>-<英小文字とハイフン>`。ファイル内でユニーク。
- `name`: 航路名。基本は港名を「〜」でつなぐ（例: 「竹原〜大崎上島（白水）」）。公式の航路名（「ひろしま世界遺産航路」等）があれば `name` に使ってよいが、港が分かるように。
- `operator`: 運航事業者名（公営は「◯◯市」「◯◯町営渡船」など）。
- `operator_url`: **必須**。運航会社・自治体の公式サイトのトップまたは航路ページ。旅行予約サイト・まとめサイト・Wikipedia は不可。https で開けるものを優先。公式サイトが無い小規模事業者は自治体・観光協会の該当ページ（そのことを notes に）。
- `route_url`: その航路の時刻表・運賃ページ（あれば。無ければ ""）。
- `service`（1つ選ぶ）:
  - `longferry` … 長距離フェリー（担当01のみ）
  - `ferry` … 自動車を航送できるフェリーが就航する航路。同じ事業者・同じ港の組み合わせで高速船も走る場合は1件にまとめて `ferry` とし、`vessels` に「フェリー・高速船」と書く。事業者や寄港地が違う場合は別件に分ける。
  - `passenger` … 旅客船・高速船・ジェットフォイル等（車は載らない）の港間定期航路（離島航路等）。
  - `sightseeing` … 観光・遊覧が主目的の定期便（周遊コース、舟下り・川下り、湖の遊覧船・海賊船など）。
  - `waterbus` … 都市内の水上バス、生活用の短距離の渡船（公営渡船など）。
- `water`: `sea`（海・湾・海峡）/ `river`（川・運河）/ `lake`（湖・沼・ダム湖）。
- `ports`: 寄港順。支線は別件。**周遊（出発港に戻る）は `loop: true` とし、ports は出発港（＋途中で乗降できる港）だけ**を並べる（最後に出発港を繰り返さない）。
- 座標: 候補リストにある OSM の終点座標・フェリーターミナル座標が使えるならそれを使う（小数5桁）。無ければ公式サイトのアクセス地図、Wikipedia 等から推定。**乗り場から数百m以内**を目標（街の中心ではなく乗り場）。
- `car`: 一般の旅客が **自家用乗用車** を載せられるなら `true`。載らない・貨物のみなら `false`。条件付き（軽自動車のみ、島民のみ、事前予約必須、台数ごく少数 等）は `true`/`false` を実態で選び `car_note` に書く（島民・事業用のみなら `false`）。
- `bike`, `bicycle`: 二輪車（バイク）/自転車の可否。不明なら `null`。
- `overnight`: **夜行便・深夜便（船内で夜を越す便）や船中泊（前泊・停泊中の宿泊）ができる便がある** なら `true`。`overnight_note` に概要（例: 「竹芝22:00発→大島6:00着の夜行便。特等〜2等、個室あり」）。昼行のみなら `false`。
- `international`, `countries`: 国際航路のみ `true` / `["JP","KR"]` 等。国内は `false` / `["JP"]`。
- `prefectures`: 寄港する都道府県（「県」「府」「都」付き）。
- `seasonal`, `season_note`: 季節運航・期間限定・冬季運休など。
- `status`: `active`（運航中。季節運休の閑散期も active）/ `suspended`（長期休航中）。
- `duration`, `frequency`, `vessels`: 分かる範囲の目安（不明なら ""）。
- `osm`: 候補リストの OSM ID で、この航路に対応するもの（区間の一部でも可、複数可）。無ければ `[]`。地図の線の形に使うので、**明らかに同じ航路のものだけ**。
- `sources`: 確認に使った URL（1件以上）。
- `confidence`: `high`（公式サイト等で2026年の運航を確認）/ `medium`（公式一覧・自治体資料等で確認、細部に不確実さ）/ `low`（2024年以前の情報しか見つからない等）。

## 調査の進め方（効率重視）
1. 自分の候補リスト `work/candidates/<番号>_<key>.md` を読む（OSM由来のチェックリスト。廃止済み・重複・名称なしを含む。**OSMに無い航路も多い**）。
2. 網羅のための一覧を探す: 各地方運輸局（北海道・東北・関東・北陸信越・中部・近畿・神戸運輸監理部・中国・四国・九州・沖縄総合事務局）の「旅客航路一覧」「旅客船事業者一覧」、都道府県の「離島航路」「定期航路」一覧、旅客船協会の会員名簿・航路図、観光協会の遊覧船一覧、Wikipedia の航路・事業者記事（発見用のみ。事実確認は公式で）など。
3. 事業者の公式サイトで、**運航中か／自家用車を載せられるか／夜行・船中泊があるか／公式URL** の4点を最優先で確認する。同じ事業者の複数航路はまとめて確認し、1事業者あたりの取得は1〜3ページ程度に抑える。
4. 所要時間・便数・バイク/自転車など細部は分かる範囲でよい（空欄可）。細部に時間をかけすぎない。
5. `WebSearch` / `WebFetch` は deferred tool なので、最初に `ToolSearch` の `select:WebSearch,WebFetch` で読み込んでから使う。PDF の一覧は Bash の `curl -sL -o work/tmp/<番号>/x.pdf <url>` → `pdftotext -layout` で読むと速い。
6. 同じ航路をフェリーと高速船で別事業者が運航している場合は事業者ごとに別件。
7. 担当外の航路に気づいたら収録せず、最終報告に「担当番号: 航路名（事業者）」で列挙する。

## 最終報告（返答）に書くこと（簡潔に）

- 確認しきれなかった点・自信の低い件
